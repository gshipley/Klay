# Klay v0.2.8

Klay now supports Xbox Game Pass PC games through
[Nexus Launcher](https://github.com/domsvoboda/nexus-launcher).
Install supported games in Nexus, import them into Klay, and launch them
alongside the rest of your library. Nexus handles Microsoft sign-in, licenses,
updates, and the game runtime.

## Highlights

- A dedicated Nexus source discovers installed games, including titles that
  have not been launched or given desktop shortcuts yet.
- Game artwork and Xbox store metadata are imported automatically.
- Green Xbox symbols identify Nexus games in the sidebar, game cards, and
  details, with shades suited to light and dark themes.
- Custom Nexus profiles can be selected in `Preferences -> Sources`.

## Fixes

- Nexus game shortcuts no longer create duplicate Desktop Entries imports.
- A failed or incomplete launcher scan no longer marks its existing games as
  removed.

## Getting Started

1. Install [Nexus Launcher](https://github.com/domsvoboda/nexus-launcher) and
   complete its account and runtime setup.
2. Install a supported Xbox PC or Game Pass game in Nexus.
3. Open Klay and run `Import`. The Nexus source is enabled by default.

A valid purchase or subscription is required. Compatibility depends on the
game and Nexus runtime; see the
[Nexus compatibility list](https://github.com/domsvoboda/nexus-launcher/wiki/Compatibility).
