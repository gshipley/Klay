# Klay v0.2.3

## Highlights
- GeForce NOW imports now pull from the fuller owned-library cache instead of just the small preview panel.
- GeForce NOW cover handling now prefers portrait-friendly art and can migrate older banner-style covers.
- Startup imports and game launches now provide clearer UI feedback with clickable progress details and launch dialogs.

## Added
- Full GeForce NOW owned-library cache parsing, including brotli-decoded app responses and paginated library recovery (`65dac44`).
- Clickable import status in the bottom-right corner so startup/background imports can open the detailed worker log (`0493751`).

## Changed
- `d2290fa` (2026-03-15): Reworked Preferences wording to make the GeForce NOW import flow clearer.
- `4f80e2f` (2026-03-15): Updated README documentation for the full GeForce NOW library import path.
- `65dac44` (2026-03-15): Improved GeForce NOW importing, cover sourcing, migration behavior, and Flatpak/runtime requirements.
- `0493751` (2026-03-15): Added import-detail and launch-feedback dialogs, with GeForce NOW stream-start handling and 10-second launch feedback for other sources.

## Fixed
- GeForce NOW imports no longer stop at the small cached library preview when the full owned-library cache is available.
- Existing GeForce NOW covers can be refreshed away from blurry landscape-derived art toward cleaner portrait presentation.
- Manual and startup imports are easier to inspect, and details-page launches now show immediate feedback instead of failing silently from the user’s perspective.

## Known Issues
- GeForce NOW totals in Klay can still exceed the GeForce NOW app because Klay expands some titles into store-specific variants and may add Steam fallbacks.
- GeForce NOW launch-feedback dismissal depends on NVIDIA’s current log markers; if those change, Klay falls back to closing the dialog when the launcher exits.
