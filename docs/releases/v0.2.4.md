# Klay v0.2.4

## Highlights
- Library cards now show compact source badges so Steam, Lutris, GeForce NOW, and other imported titles are easier to identify at a glance.
- Lutris imports now handle deleted/reinstalled libraries more safely when Lutris reuses game IDs.
- Klay now clears old imported cover files before refreshing cover art, preventing recycled IDs from showing artwork from removed games.

## Added
- Source badges on library cards for imported game origins (`14376f7`).
- README disclosure describing how AI assistance is used during development (`3cd2fbf`).

## Changed
- Library card source badge pixmaps are cached to reduce repeated rendering work while browsing (`9381ca8`).

## Fixed
- Lutris imports now delete existing cached covers before adding or reviving imported games, so a reused Lutris ID cannot keep stale artwork from a removed title (`5f23f6c`).
- Recycled Lutris IDs with a different title are now treated as fresh game identities instead of inheriting hidden state, categories, or play history from the old Klay record (`5e7d5bd`).

## Known Issues
- No new known issues in this release.
