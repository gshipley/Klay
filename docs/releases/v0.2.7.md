# Klay v0.2.7

This release adds an optional offline jail for local Windows games. Each game
gets its own game copy, Windows environment, home folder, and saves, while the
original installation is left untouched.

## Highlights

- Enable `Run in a jail (offline)` when editing a game. Klay detects installed
  Lutris Windows games, runners, and supported Windows shortcuts; `Advanced
  settings` provides manual setup when needed.
- Later launches reuse the private game copy and saves. `View Jail Log`,
  `Open Jail Folder`, and `Stop Jail` help inspect launches and recover from a
  stuck game.
- Compatible standard Linux gamepads connected before launch are available
  inside the jail.

## Before You Use It

- Install Python 3.11 or newer, Bubblewrap (`bwrap`), and a trusted Wine or
  Proton runner on the host. Klay checks them but does not install them.
- The first launch needs time and disk space for a full game copy and a new
  Windows environment. Preparation cannot currently be cancelled with
  `Stop Jail`; closing Klay waits for it to finish.
- Saves and changes are not synchronized with the original game. Turning jail
  mode off restores the normal launch command and keeps the jail. Deleting a
  jail also deletes its saves, so back them up first.
- The jail shares the Linux kernel, GPU, audio, and desktop services, especially
  X11. It reduces exposure without providing virtual-machine isolation or
  certifying that a game is safe. Klay's own launcher permissions are unchanged.

## Known Issues

- Online sign-in, DRM, multiplayer, cloud saves, downloads, anti-cheat, or
  missing Windows dependencies can prevent games from working. Existing Lutris
  prefixes and launch scripts are not reused. Compatibility varies by game
  and runner.
- Connect or pair controllers before launch. A new connection or reconnect
  may require relaunching the game. Raw HID features and Steam Input integration
  are not provided.
- GE-Proton11-3 has a known Unity video playback crash associated with an
  upstream Media Foundation issue. Another trusted installed Proton build may
  work for an affected game; a newer build is not a guaranteed fix.
- Some Proton builds try to download optional upscaler components during
  startup. Those requests fail in the offline jail and can appear in the log
  even when the bundled graphics components initialize successfully.

See the [game jail guide](https://github.com/gshipley/Klay/blob/v0.2.7/docs/game-jail.md) for setup, saves, the isolation
boundary, diagnostics, and the runner issue reference.
