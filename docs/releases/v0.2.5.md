# Klay v0.2.5

## Highlights
- A new couch-friendly Big Picture Mode provides a fullscreen library with larger game cards and simplified controls.
- Native Linux controller support enables D-pad and left-stick navigation, A/Cross activation, B/Circle back navigation, and Start/Menu access to the main menu.
- Klay can now be closed without reaching for a keyboard by selecting `Quit Klay` from the controller-accessible main menu.

## Added
- Big Picture Mode, available from the main menu, with `F11`, or at startup with `klay --big-picture` (`2ecddda`).
- A `Start in Big Picture Mode` preference for couch and handheld setups.
- Controller hotplug detection and connection status in the Big Picture header.
- Flatpak access to native input devices for controller navigation.
- A controller-accessible `Quit Klay` menu action.

## Changed
- Big Picture Mode uses larger covers, roomier game details, simplified actions, and fullscreen presentation for viewing at a distance.
- The README now documents Big Picture startup, keyboard controls, controller navigation, and controller-based quitting.

## Fixed
- Controller users no longer need a keyboard or mouse to close Klay from Big Picture Mode.

## Known Issues
- No new known issues in this release.
