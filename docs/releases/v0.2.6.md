# Klay v0.2.6

This release fixes one bug.

## Fixed
- The **Activating a game card launches it instead of opening details** preference now works when clicking a game card. Previously, mouse clicks always opened the details page even when the preference was enabled. Double-clicking does not launch the game twice.

## Download
- `com.grantshipley.Klay.Devel.flatpak`

## Install
```bash
flatpak install --user --reinstall ./com.grantshipley.Klay.Devel.flatpak
flatpak run com.grantshipley.Klay.Devel
```
