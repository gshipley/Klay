# Klay v0.2.9

This security update refreshes Klay's bundled dependencies and protects artwork
imports against oversized downloads and images. Updating is recommended for all
Flatpak users.

## Security fixes

- Update Brotli to 1.2.1 to fix a decoder memory-corruption vulnerability that can
  be reached through compressed HTTP responses
  ([CVE-2026-111497](https://github.com/google/brotli/releases/tag/v1.2.1)).
- Update Pillow to 13.0.0, including fixes for crafted image files that can cause
  memory corruption or excessive resource use
  ([PSD advisory](https://github.com/python-pillow/Pillow/security/advisories/GHSA-cfh3-3jmp-rvhc),
  [TIFF/EXIF advisory](https://github.com/python-pillow/Pillow/security/advisories/GHSA-wqgw-9xfh-qf2g)).
- Update certifi to 2026.10.23 to remove trust affected by compromised certificate
  authority keys
  ([advisory](https://github.com/certifi/python-certifi/security/advisories/GHSA-6q48-6c7w-9gw2)).
- Update urllib3 to 2.8.0 and idna to 3.20 to address malicious HTTP response and
  domain-name processing issues. Refresh Requests to 2.34.2 as well.
- Update PySide6 and its bundled Qt libraries to 6.11.3, including fixes for
  malicious SVG files
  ([Qt advisory](https://www.qt.io/blog/security-advisory-cve-2026-8168)).
- Move the Flatpak runtime and SDK from GNOME 49 to supported GNOME 51.

## Additional protection

- Limit artwork download sizes, decoded image dimensions, and animation frames.
- Validate supported image formats before saving covers.
- Pin build actions and containers to immutable revisions, restrict release-token
  permissions, and check pinned Python dependencies against current advisories
  automatically.

Xbox PC and Game Pass support through
[Nexus Launcher](https://github.com/domsvoboda/nexus-launcher) remains available.
