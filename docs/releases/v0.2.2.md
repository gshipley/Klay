# Klay v0.2.2

## Highlights
- GeForce NOW imports now support richer multi-store metadata end-to-end.
- Game details now show clearer source/store badges with new store logo assets.
- Release automation/docs were updated so tag-driven releases generate cleaner notes.

- Store logo assets: `assets/images/epic_logo.png`, `assets/images/ubisoft_logo.png`, `assets/images/xbox_logo.jpg`, `assets/images/xbox_logo.png`, and `assets/images/xbox_logo.svg` (`132d2b1`).
