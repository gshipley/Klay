# Klay v0.2.2

## Highlights
- Game details now show both source and store badges for GeForce NOW entries.
- Store metadata is now preserved and updated on import, even for existing games.
- Source/store logos were resized and aligned for better readability in the details header.

## Added
- New store logo assets for Epic, Ubisoft, and Xbox.
- Store normalization and fallback detection for GeForce NOW game variants.

## Changed
- Details header badge sizing and spacing to keep source/store logos visually consistent.
- Library search now includes the `store` field.

## Fixed
- GeForce NOW imports now attach `store` to additional metadata payloads.
- Duplicate/import refresh flow now updates stored `store` data instead of skipping it.

## Known Issues
- Unknown store slugs may show text-only store labels until matching logo assets are added.

## Download
- `com.grantshipley.Klay.Devel.flatpak`

## Install
```bash
flatpak install --user --reinstall ./com.grantshipley.Klay.Devel.flatpak
flatpak run com.grantshipley.Klay.Devel
```
