# Translations

This directory contains gettext translation infrastructure for Klay.

Legacy Cartridges `.po` catalogs were removed during the Klay rebrand cleanup.
New Klay-specific translations can be added by:

1. Creating or updating locale catalogs in this directory (`<locale>.po`).
2. Adding locale codes to `LINGUAS` (one per line).
3. Keeping `POTFILES` in sync with translatable source files.
